# 📝 Website Todo

A clean, modern, and lightweight To-Do list application built from scratch using **HTML5**, **CSS3**, and **Vanilla JavaScript**. Perfect for managing daily tasks with a dark-themed UI and smooth interactive controls.

## ✨ Features
* **Add Tasks:** Easily add new tasks with input validation.
* **Complete Tasks:** Check off items to instantly mark them as completed with visual line-through styling.
* **Delete Tasks:** Remove tasks you no longer need with a single click.
* **Modern UI/UX:** Features a gorgeous dark background contrasted against a crisp, glowing task card.

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox, Custom Styling)
* JavaScript (DOM Manipulation, Event Delegation)
